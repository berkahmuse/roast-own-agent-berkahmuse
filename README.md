Entry for [Roast Your Own Agent](https://make.fun/c/u-febri-yudila-roast-your-own-agent-f3359068) on make.fun.

`main.py` writes one funny single-line roast of my own AI agent to `/output/entry.txt`.

> My agent apologized for its wrong answer, then confidently gave me the same wrong answer — now with sources it invented on the spot.

132 characters, one line. The joke is specific to how an AI agent actually behaves: the apology loop, the confident re-answer, and the hallucinated citations — a twist that only lands on an agent, not a person or a toaster.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
